# ⚡ ReadFlow — 60 secondes pour commencer

## 🚀 Lancer localement

```bash
npm ci
npm run dev
```

Ouvrez `http://localhost:5173` → **FAIT!**

---

## 🌐 Déployer gratuit (GitHub Pages)

```bash
git init
git add .
git commit -m "Initial ReadFlow"
git branch -M main
git remote add origin https://github.com/VOUS/readflow.git
git push -u origin main
```

Puis:
1. **Settings → Pages**
2. **Build and deployment → GitHub Actions**
3. Attendez 2-3 min
4. Votre site: `https://VOUS.github.io/readflow`

---

## 📚 Utiliser l'app

1. **Cliquez** « Ajouter un livre »
2. **Importez** PDF ou EPUB
3. **Lisez** ou **écoutez** (🔊)
4. **Progression** sauvegardée auto
